# THULIR: Student Early-Warning & Support System

**Tagline:** *Recognize Early. Support Better. Grow Together.*  
**Context:** Government Higher Secondary Schools, Dept. of School Education, Tamil Nadu.

THULIR is a secure, explainable decision-support platform designed to help school staff (Administrators, Class/Subject Teachers, and Student Counsellors) notice students who may need academic or attendance support and coordinate human interventions.

> **Important Disclaimer:**  
> THULIR is **NOT** an emotion detector, a diagnostic medical tool, or an automated dropout predictor. Every warning indicator generated by the system is solely an objective prompt for human review by educators and counsellors.

---

## 1. Architecture Overview

- **Frontend:** React 18, Vite, Tailwind CSS (Stitch *Institutional Civic Trust* design system tokens), React Router v6, Recharts, Lucide React icons, and `react-i18next` (English & Tamil).
- **Backend:** Python 3.14, FastAPI, SQLAlchemy 2.0, Pydantic v2, Pandas.
- **Database & Migrations:** SQLite for local dev & testing (PostgreSQL/Supabase compatible schema); managed via Alembic migrations.
- **Authentication & RBAC:** Session-based authentication with bcrypt password hashing, HttpOnly cookies, login rate limiting, and strict server-side role authorization (`admin`, `teacher`, `counsellor`).
- **Early-Warning Engine:** Pure, deterministic rule-based Python module with evidence fingerprinting, boundary handling, and human explainability notes.

## 2. User Roles & Least-Privilege Permissions

| Capability | Admin (Headmaster) | Subject Teacher | School Counsellor |
|---|---|---|---|
| **Student Directory** | All students in school | Assigned classes only | Assigned support cases only |
| **Warning Review** | All school indicators | Assigned class indicators | Assigned case indicators |
| **Case Management** | Full school overview | Create & update assigned cases | Create & update assigned cases |
| **Sensitive Notes** | Redacted by default | Redacted | **Full access for assigned cases** |
| **Data Import** | **Yes** (CSV / XLSX with preview diffs) | No (403 Forbidden) | No (403 Forbidden) |
| **Reports & Export** | School-wide reports & CSV export | Class-level summaries | Case-level summaries |

## 3. Quick Start & Local Setup

### Prerequisites
- Node.js (v18+) & npm
- Python (3.12+) via `uv` or system virtual environment

### Backend Setup
```bash
# Navigate to backend
cd backend

# Create venv and install dependencies
uv venv .venv --python 3.14
.\.venv\Scripts\python.exe -m pip install -r requirements.txt

# Run migrations
python run_alembic.py upgrade head

# Run server
.\.venv\Scripts\uvicorn.exe backend.app.main:app --reload --port 8000
```

### Frontend Setup
```bash
# Navigate to frontend
cd frontend

# Install dependencies
npm install

# Start development server
npm run dev
```
The frontend will start at `http://localhost:5173` with proxy configured to `http://localhost:8000`.

## 4. Testing & Verification

THULIR is backed by an automated test suite verifying schema, auth/RBAC, warning rules, student scoping, support cases, and import guardrails:

```bash
# Run backend pytest suite (57 tests)
backend\.venv\Scripts\pytest.exe backend/tests/ -v

# Run frontend vitest suite (i18n & translation checks)
cd frontend
npx vitest run

# Run production build
cd frontend
npm run build
```
